# Matheus Corrêa · portfolio

Source of [milhoando-dot.github.io/portfolio](https://milhoando-dot.github.io/portfolio/), my personal portfolio.

Plain HTML, CSS and JavaScript in a single file: no framework, no build step, no trackers.
Portuguese lives in the HTML, so the page works without JavaScript; English comes from a small
dictionary and follows the browser language (the choice is remembered).

- 100 for accessibility, best practices and SEO on Lighthouse
- respects `prefers-reduced-motion`: the marquee and the reveal animations turn off
- both résumés (PT and EN) ship as PDFs next to the page
